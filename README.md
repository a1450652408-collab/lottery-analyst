# 福彩数据分析师

📊 双色球 · 大乐透 · 快乐8 · 福彩3D · 排列三 · 排列五 · 七星彩 · 七乐彩

全彩种开奖数据分析 + 智能推荐，零外部依赖单文件应用。

## 访问地址

https://a1450652408-glitch.github.io/lottery-analyst/

## 功能

- 📊 分析页：频率分布、和值走势、奇偶比、区间分布、最新开奖
- 🎯 推荐页：基于差异化算法（乐透/基诺/数字型）生成 2 注基本推荐 + 3 注胆拖推荐
- 📈 遗漏值走势、冷热号追踪
- ❤️ 收藏管理（本地存储）

## 算法

| 类型 | 期数 | 策略 |
|------|------|------|
| 乐透型（双色球/大乐透/七乐彩）| 近30期 | 区间均衡 + 冷热号 + 蓝球独立追踪 |
| 基诺型（快乐8）| 近100期 | 综合权重 = 遗漏×60% + 频率×40% |
| 数字型（3D/排三/排五/七星彩）| 近100期 | 按位独立分析：热号/冷号/大小/奇偶/走势 |

## 自动更新

GitHub Actions 每日 UTC 0:00 自动抓取最新开奖数据并更新。
